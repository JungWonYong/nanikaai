## はじめ方

- **実行ファイル**: [GitHub Releases](https://github.com/JungWonYong/nanikaai/releases/latest) から展開して起動（初回吹き出しから 1 クリックで無料ローカル AI を自動準備）。
- **AI エージェントで全自動導入（`agy` / `claude`）**:

```bash
agy -i "https://github.com/JungWonYong/nanikaai の最新リリース実行ファイルとローカルOllamaをこのPCに導入・起動し、スペックに合う無料モデル(gemma4/llama3系)を接続して動作確認まで完了して。"
```
